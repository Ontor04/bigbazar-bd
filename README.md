# BIG BAZAR BD – অনলাইন শপ + অ্যাডমিন প্যানেল

বাংলা (প্রধান) ও ইংরেজি ভাষা, ক্যাশ অন ডেলিভারি, লাইভ সার্চ, রিভিউ, অ্যাডমিন প্যানেল – সব একসাথে।
ডাটাবেস: SQLite (`data/bigbazar.db`) – আলাদা কিছু ইনস্টল করতে হয় না।

## ১. কম্পিউটারে চালিয়ে দেখা (Python 3.10+ লাগবে)

    pip install -r requirements.txt
    ADMIN_PASSWORD='আপনার-পাসওয়ার্ড123' python app.py        # Windows (PowerShell): $env:ADMIN_PASSWORD='...'; python app.py

তারপর ব্রাউজারে খুলুন: http://127.0.0.1:5000
অ্যাডমিন লগইন: http://127.0.0.1:5000/admin/login   (ইউজারনেম: `admin`)

* `ADMIN_PASSWORD` না দিলে প্রথমবার চালানোর সময় একটি র‍্যান্ডম পাসওয়ার্ড টার্মিনালে একবারই দেখানো হয় – সেটা সেভ করে রাখুন।
* পাসওয়ার্ড ভুলে গেলে: `python app.py reset-password`
* পাসওয়ার্ড কমপক্ষে ১০ অক্ষর, অক্ষর + সংখ্যা মিলিয়ে।

## ২. ইন্টারনেটে লাইভ করা (আসল দোকান)

এটি একটি Python (Flask) অ্যাপ – Blogger/Blogspot-এ চলবে না। চালাতে হবে Python হোস্টিংয়ে
(যেমন VPS, PythonAnywhere, Render, Railway)। চালানোর কমান্ড:

    gunicorn -w 2 -b 0.0.0.0:8000 wsgi:app

লাইভ করার সময় এই environment variable গুলো দিন:

| নাম | কাজ |
|---|---|
| `ADMIN_PASSWORD` | প্রথম অ্যাডমিনের পাসওয়ার্ড |
| `ADMIN_PATH` | অ্যাডমিন লিংক বদলান, যেমন `/boss-panel-7x` (অনুমান করা কঠিন হয়) |
| `FORCE_HTTPS=1` | HTTPS চালু থাকলে কুকি আরও নিরাপদ হয় |
| `TRUST_PROXY=1` | Nginx/Cloudflare-এর পেছনে চালালে |
| `DATA_DIR` | ডাটাবেস ও আপলোড করা ছবির ফোল্ডার (স্থায়ী ডিস্কে রাখুন!) |
| `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `SMTP_FROM` | ইমেইল পাঠানো (পাসওয়ার্ড রিসেট, নতুন অর্ডারের খবর) |
| `PUBLIC_URL` | সাইটের পুরো ঠিকানা, যেমন `https://bigbazarbd.com` |

**গুরুত্বপূর্ণ:** `DATA_DIR` ফোল্ডারের নিয়মিত ব্যাকআপ নিন – সব অর্ডার, পণ্য ও ছবি সেখানে থাকে।
SMTP না দিলে "পাসওয়ার্ড ভুলে গেছি"-র লিংক `data/outbox.log` ফাইলে লেখা হয়, ইমেইল যায় না।

## ৩. অ্যাডমিন প্যানেলে যা যা করা যায়
